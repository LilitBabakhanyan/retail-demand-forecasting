# Data

The data comes from the Walmart Store Sales Forecasting competition on Kaggle:
https://www.kaggle.com/competitions/walmart-recruiting-store-sales-forecasting/data

Download the files from Kaggle and place them in this folder:

- train.csv: weekly sales per store and department
- test.csv: test set provided by the competition
- features.csv: external variables (temperature, fuel price, markdowns, CPI, unemployment)
- stores.csv: store type and size

The CSV files are not included in this repository. See the Kaggle page for the dataset terms.
